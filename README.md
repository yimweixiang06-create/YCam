> **不必为了体验新式相机界面、摄影风格调色盘和胶片色彩，就一定要换一部支持 iOS 27 的 iPhone。**

**YCam** 是一款面向 iPhone 用户打造的独立相机应用，**最低支持 iOS 18.0**。它参考新一代 iPhone 相机的操作理念，重新设计了简洁的拍摄界面，并将可自由调整的**摄影风格调色盘**带到 iOS 18 设备上，同时加入富士（FUJI）、柯达（KODAK）风格的胶片色彩，让日常随手拍也有更多创作空间。

无论是记录生活、拍摄人物、旅行风景，还是尝试复古胶片色彩，你都可以在同一个相机里完成。

**请注意：** YCam 是第三方独立开发的相机，不是苹果官方相机，也不是 iOS 27 系统功能移植版。界面与摄影风格属于自主实现的**近似体验**，并不使用苹果、富士或柯达未公开的原生色彩算法。

## ✨ YCam 有什么特别？

### 📱 iOS 18，也能使用新式相机体验

YCam 专门照顾仍在使用 **iOS 18** 的 iPhone 用户，同时也面向较新 iOS 版本：

- **新一代相机风格界面**：参考 iOS 27 的简约拍摄布局与操作方式，提供「**视频｜照片｜人像**」三种主要模式。
- **自然的模式切换**：点按或左右滑动切换，选中指示器会随手指移动，松手后吸附到最接近的模式。
- **摄影风格调色盘**：不需要 iOS 27，也能在 YCam 里选择风格，并通过点阵调色盘调整个人喜欢的色彩。
- **玻璃质感的控制区**：使用磨砂、高斯模糊风格的面板；不同 iOS 版本根据系统可用能力显示相应效果。
- **可自定义的六点控制菜单**：常用功能可以整理并固定到顶部，让拍摄画面保持清爽。
- **竖屏与横屏拍摄**：为不同握持方向安排控制按钮和取景画面。

这是 **YCam 自己实现的相机体验**，因此不要求手机必须运行 iOS 27。实际可用功能仍以设备摄像头硬件及系统 API 支持情况为准。

### 🎨 摄影风格：不是只有「套一个滤镜」

普通滤镜往往只有几种固定颜色。YCam 的摄影风格除了预设外，还允许你继续调整：

| 调节项目 | 可以做什么 | 初始值 |
| --- | --- | --- |
| **色调** | 改变画面的亮暗气氛、层次与对比感觉 | **0** |
| **颜色** | 调整整体的冷暖与色彩倾向 | **0** |
| **调色盘强度** | 控制所选摄影风格的作用程度 | **100** |

你可以**点击调色盘上的小圆点**，也可以用手指拖动大圆点。大圆点会停在点阵上，而不是落在空白处。

**所有摄影风格默认都是「色调 0、颜色 0、强度 100」**，让你先看到每种风格本来的设定，再决定要不要继续调整。这里的数值是 YCam 的调节刻度，不是苹果未公开的官方参数。

### 🎞️ 28 种摄影风格，包含富士与柯达胶片灵感

YCam 目前内置 **28 种摄影风格**，从自然、冷暖色调、人像氛围到胶片模拟，都可以根据题材选择。

**日常与创意摄影风格**包括：标准、珠光、琥珀色、金色、玫瑰金、冷调玫瑰色、冷调、自然、鲜明、温馨、空灵、戏剧、明亮、耀目与黑白。

**富士（FUJI）风格**包括：

- FUJI 400、FUJI 青调
- PROVIA、Velvia、ASTIA、REALA ACE
- 经典铬（Classic Chrome）、经典负片（Classic Negative）
- PRO Neg、ETERNA、ETERNA BB

**柯达（KODAK）风格**包括：

- KODAK 800
- KODAK 暖黄

此外还有 **10 种传统照片滤镜**，包括原图、鲜明、鲜暖色、鲜冷色、戏剧、戏剧暖色、戏剧冷色、单色、银色调与黑白。你可以选择摄影风格，也可以使用传统滤镜，探索不同的画面效果。

其中部分富士风格使用项目内置的 **3D LUT 色彩查找表**，其他风格使用独立的色彩配方。**这些是受到经典胶片和色彩审美启发的模拟效果，不是富士或柯达官方授权的胶片模拟或原厂算法。**

### 📸 认真拍照，也照顾日常操作

- **照片模式**：自动请求当前摄像头支持的最高照片分辨率，不提供额外的「一半／最大」档位。
- **视频模式**：根据设备支持情况提供 HD／4K 与不同帧率选项；界面可采用 4:3 的取景构图，**并不代表视频文件本身一定是 4:3**。
- **人像模式**：通过人物分割与图像处理，尝试让人物保持清晰、背景柔和虚化；可以自行调整景深与人像光效。
- **实况照片（Live Photo）**：在硬件及格式允许时，照片和人像模式都可以尝试使用；并非所有最高分辨率或 RAW 拍摄组合都支持实况。
- **常用拍摄辅助**：网格、倒计时、曝光、对焦、白平衡、直方图等，按需要使用。
- **双指缩放**：在取景画面上直接捏合放大或缩小，减少不必要的悬浮控制栏。

为了保留最高画质，YCam 不会仅为了启用实况照片而悄悄把照片分辨率降低一半。

## ⚙️ 它是怎样运作的？用简单的话来解释

可以把 YCam 想象成一台拥有自己「数字暗房」的相机。

**第一步：iPhone 负责拍摄。**  
YCam 通过苹果提供的 **AVFoundation** 相机接口读取镜头画面、控制拍照与录像。它依然使用手机原本的摄像头，并不会凭软件增加手机没有的镜头或传感器。

**第二步：YCam 为画面调色。**  
你选择一个摄影风格后，应用会把相应的亮度、对比度、冷暖、颜色倾向等组合成色彩配方。部分胶片风格还会使用 **3D LUT** —— 你可以把它理解成一张非常精细的「颜色转换地图」，告诉程序原本的颜色应该怎样变化。

**第三步：实时预览并保存作品。**  
YCam 使用苹果公开的 **Core Image** 等图像处理技术，尽可能让取景预览与拍摄结果采用一致的风格处理。调色时，控制圆点先快速跟随手指，后台再合并重复的滤镜计算，避免每移动一点就让整个画面重新工作。

**第四步：人像模式额外处理背景。**  
当需要景深效果时，应用利用人物分割估计主体区域，再对背景应用模糊等效果，尽量保持人物主体清晰。它属于软件人像处理，不等同于所有 iPhone 的原生深度传感器或苹果私有的人像算法。

### 🚀 为什么还要专门优化流畅度？

相机需要一边显示取景画面，一边处理颜色，有时还要录像、辨认人物及保存照片。YCam 为此加入了多项处理：

- 让模式切换与调色盘的手指跟踪优先响应，不让复杂的滤镜计算阻挡基本操作。
- 利用 Core Animation、Core Image 及后台处理队列分担工作，合并连续的调色请求。
- 在没有额外滤镜效果时，减少不必要的图像重算。
- 在设备负载或温度升高时，适当调整**实时预览**的处理负担，而不是随意牺牲最终照片的最高分辨率。
- 在照片与视频的相机硬件配置切换期间，尝试保留上一帧，减少短暂黑画面的视觉干扰。

这些设计目标是让操作更自然、更省资源，但**不能保证所有 iPhone 都达到系统原生相机的帧率、温度或零延迟体验**。

## 🛠️ 如何获取并安装？

普通用户可以直接进入仓库右侧的 **Releases（发行版）** 栏目，选择最新版本，在 **Assets** 下载 IPA 并阅读更新日志。

本项目也提供 GitHub Actions 构建未签名 iPhone 安装包，方便开发与测试：

1. 打开本仓库的 **Actions** 页面。
2. 选择 **Build YCam for Sideloadly**，运行构建工作流。
3. 构建成功后，在运行页面下载 **YCam-unsigned-IPA**。
4. 解压得到 **YCam-unsigned.ipa**，再通过 **Sideloadly** 使用你自己的签名方式安装到 iPhone。

**为什么构建要用较新的 Xcode，手机却只需要 iOS 18？**  
这是两件事：开发和编译 YCam 使用较新的 iPhone SDK；应用本身的**最低运行版本设为 iOS 18**，并会对不同系统能使用的界面能力做适配。下载到的 IPA 是**未签名开发构建**，不等于 App Store 上架版本。

开发者可用以下命令运行项目静态检查：

```bash
python3 tools/static_check.py
python3 tools/style_check.py
python3 tools/verify_user_layout_max.py
```

需要排查故障时，可使用相机页面的诊断日志入口收集信息。
